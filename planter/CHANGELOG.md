# 바뀐 기록 (Changelog)

허브 화분 아파트(Biopolitika) 모델과 시험의 바뀐 기록이다. 모든 항목은 git 커밋에 묶여 있어, 괄호 속 해시로 그때의 파일을 그대로 꺼낼 수 있다.

```
git log --oneline -- planter          # 커밋 목록
git show <해시> --stat                 # 그 커밋에서 바뀐 파일
git checkout <해시> -- planter/stl     # 그때의 STL 꺼내기
```

- 새 항목은 위에 쌓는다. 모델을 바꾸는 커밋마다 여기에 한 줄 이상 적는다.
- **발견**은 실제 출력과 시험에서 알게 된 것이다. 모델에서 계산으로 찾은 것과 나눠 적는다.

## 2026-11-27 · 필로티를 버리고 받침판으로

- **발견 (구조 시험, 필로티 바닥):**
  - 코어 이음(꽂이 20 mm, 틈 0.15)은 버텼다.
  - 맨 위 두 팔의 물 추 통에 물을 채우고 사이 각을 좁히자 약 150°에서 넘어갔다(한 팔을 가득 채운 쏠림의 약 절반).
  - 바닥에 눕힌 팔은 무게가 바닥으로 바로 가서 코어를 붙잡지 못했다. 갈고리는 매달릴 때만 일한다.
- **결정:** 필로티 대신 받침판. 맨 아래 층도 팔이 매달린 물길 층. 한국 아파트에는 필로티가 없다(빌라의 것)는 점에서 개념에도 맞다.
- **맨 아래 코어** (`core(core_bot(), true)`): 가운데 마디와 같은 물길 층에 꽂이 대신 팔 아래 기둥. 집수 바닥(원뿔, 팔 아래 25 mm)과 대각선 배수 관 자리. 밸브 손잡이 윗면이 팔 아랫면보다 3 mm 낮다. 아래 끝 50 mm(반 크기 25)가 판 소켓에 틈 0.15로 꽂힌다.
- **받침판** (`plate`): 480 × 480(반 크기 240 × 240), 소켓, 45° 밑동, 아랫면 TPU 패드 홈 넷. 실물은 A2L 판보다 커서 나눠 뽑거나 판재를 쓴다.
- 확인: 반 크기와 실물에서 판, 맨 아래 코어, 팔 넷, 물받이, 바구니, 마개, 밸브, 위 코어 사이 겹침 없음. 받이 지붕과 집수 바닥에 뚫린 곳 없음(세로 광선 검사). 가운데 코어는 바뀌지 않음(부피 같음).
- `water_test.scad`: 받침 발 대신 받침판, 맨 아래 층부터 물길 층. `struct_test.scad`: 같은 받침판과 매달린 맨 아래 층.

## 2026-11-25 · 물 시험에서 찾은 것과 구조 보강

- **실제 출력 시간, 옛 팔 호환** (`f2a235f`)
  - 발견: 실제 출력은 README 표(PrusaSlicer 보수적 추정)의 약 60%다.
  - 발견: 먼저 뽑은 팔이 창을 넓히기 전 팔이었다. 물받이와 물 추 통은 맞고, 바구니는 안 걸리며, 마개는 좁은 창으로 내려 꽂기 어렵다. 구조 시험의 바닥 팔로 다시 쓴다.
- **코어 꽂이 보강과 구조 시험 모델** (`12fa1ff`)
  - 코어 꽂이 18 → 40 mm(반 크기 9 → 20), 꽂이 틈 0.25 → 0.15 mm.
  - 맨 아래 코어 밸브 자리 옆면을 바닥 팔 갈고리가 지나가는 만큼 비웠다(반 크기에서 약 1 mm 겹쳤다. 계산으로 찾음).
  - 물 추 통(`tank`) 추가: 물받이 자리에 넣는 막힌 통. 붓는 mL = 무게 g, 최대 약 180 mL, 25 mL 눈금.
  - `struct_test.scad`: 필로티 바닥 + 팔 없는 1층 코어 + 물 추 통을 넣은 맨 위층.
  - 정정: 물받이는 팔 입구(대각선 판 사이 약 72 mm, 반 크기 41 mm)보다 넓어 눕힌 채로는 못 들어간다. 옆으로 세워 넣고 안에서 눕힌다. `26202fa`의 "열린 끝을 지나간다"는 설명은 틀렸다(경로 계산으로 찾음).
  - 정정: 탑 넘어짐 계산은 바닥 팔과 맨 아래 코어가 한 덩어리라고 가정했다(3.8 kgf). 갈고리는 들림을 막지 못하므로 약 0.9 kgf일 수 있다. 구조 시험에서 확인한다.
- **진행 기록 시작** (`b2c5340`)
  - 발견: 팔 하나만 걸면 탑이 넘어진다. 꽂이가 9 mm(지름 41 mm)로 얕아, 한쪽 무게에 위 코어가 테두리를 축으로 들린다. 받침 발 고리(6 mm)도 넘어짐을 막지 못한다.
  - 발견: 코어 위 끝 속 모따기 테두리가 반 크기에서 조금 뭉개진다(평평한 면 0.85 mm). 앉는 데는 문제없어 그대로 둔다.
  - 계획: 물길 확인 → 구조 보강 → 실물 제작.
- **팔 부품 한 판** (`c55d563`): 물받이, 바구니, 마개, 밸브 몸통과 마개.
- **팔과 코어 이음 그림** (`11b7db9`): `renders/arm_core_joint.png`.
- **집수 바닥 틈 막음** (`8399929`)
  - 발견: 맨 아래 코어의 원뿔 바닥 가장자리, 밸브 구멍 앞에 틈이 보였다(빛이 비침).
  - 원인: 밸브 관이 끼는 넓은 구멍을 코어 속까지 파서 원뿔을 뚫었다.
  - 수정: 코어 속에서는 관 물길만 파고, 넓은 구멍은 벽 안에서만 판다. 원뿔 전체를 세로 광선으로 검사해 구멍이 없음을 확인했다.
- **반 크기 시험 탑 다시 그림** (`3ef8552`).
- **물높이, 옆 물길, 심는 바구니, 창 폭** (`26202fa`)
  - 발견(검토): 수경재배에는 창에서 물까지 너무 깊고 물이 적다.
  - 물높이를 팔 축 아래 44 → 32 mm로(깊이 약 3 cm, 실물 0.5 L). 물받이 위쪽을 세로벽으로.
  - 들어오는 물길을 −y 벽으로 옮겨, 창 아래 전체가 뿌리 칸 하나가 됐다. 넘침 둑과 주둥이는 +y 하나. 마개는 옆 물길에.
  - 심는 바구니 추가: 창에 걸쳐 물속까지 내려가고, V자 바닥에 틈.
  - 창 수정: 둥근 위 벽을 얇게만 잘라 실제로는 약 30 mm만 열렸다. 64 mm 전체가 열리게 위 벽을 세로로 뚫었다.

## 2026-11-24 · 십자 층과 같이 쓰는 물길
